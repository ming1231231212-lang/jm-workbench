# 新手工作台与执行可靠性

## 用户路径

打开默认进入“今日工作”，查看正在执行的阶段、今天的平台回执与需要处理的缺口。日常动作只有写内容、发布安排、账号。采集、素材、视频和高级设置收纳到更多工具，历史数据不删除。所有结果区分草稿、排队、平台接收、用户登记、公开可见和结果不明。

## 执行边界

网页在线与执行器健康独立。真实平台调用经 `BoundedCommunityAdapter → ProcessBoundary → browser_task → CommunityAdapter`，账号凭据通过标准输入传递，不放命令行、日志或临时文件。连接30秒、账号检查60秒、查找原帖120秒、提交180秒；超时终止本次子进程及其驱动进程，不终止用户的 Chrome。等待期间 API 可读取具体阶段与截止时间。测试注入的适配器仍直接执行。

只读超时属于未提交，可按退避检查；提交阶段超时属于结果不明，保留占位并暂停原平台，禁止自动重发。其他平台下次轮询仍可处理。服务中断原 running 同样转 unknown。启动恢复不解除手动停止与真实平台限制；重复点击使用原请求标识和数据库唯一约束。

同一个执行器同时只允许一个平台浏览器操作；用户检查连接与定时提交重叠时，返回明确的“当前动作未提交”，不另开并发控制连接。网页读取20秒无响应会给出重连提示；写请求超时提醒先查记录，不能把网络超时解释成发布失败后直接重发。

Windows 使用 Job Object：先以暂停状态创建平台子进程，加入本次专属进程组后恢复启动；超时直接终止这组进程。驱动的子进程不能逃逸，服务退出时组句柄关闭也会结束它们。日常 Chrome 是外部已有进程，不加入这组。并行验收曾发现 taskkill 命令启动延迟可能造成超时后的迟到写入，因此取消了该实现，并补充子进程树和无关进程保护测试。API参考：<https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects>。

网页查看和10秒刷新只读已有状态，不再自动连接浏览器核验所有账号。用户完成登录后点击检查连接，执行前仍强制核验固定账号身份。浏览器登录不等于工作台已经连接。

## 扩展能力

平台注册表明确声明本地草稿、网页打开、链接登记、自动提交、自动评论、每日计划等能力。微博、微信公众号提供本地内容管理与网页发布流程；未验证的自动提交入口保持关闭。公众号个人号的接口发布权限不得推断为可用，网页发布完成后登记真实链接。

## 测试边界

真实子进程故障注入检查超时终止、无延迟写入、错误分类、停止；服务测试检查占位、去重、未知结果不重发、账号变化拒绝、共享预算、计划恢复。前端使用隔离本地假数据与离线页面测试导航、编辑删除、草稿、结果、窄屏和键盘操作。测试不向真实社区发送内容。真实账号发布仍需独立回执验收。

验收入口：`python -m pytest`、`npm test`、`python -m scripts.verify_novice_ui`、`python -m scripts.verify_community_v2_ui`、`python -m scripts.verify_workspace_ui`、`python -m scripts.verify_publishing_ui`。浏览器验收创建无账号的临时 headless Chromium，拦截外部网络，完全不连接历史 Codex-Chrome 或日常 Chrome。结果写入 outputs，真实平台数据只在原 var 中。

升级时先停旧服务及其平台驱动，备份数据库。旧 running 按恢复规则保留 unknown；旧代码下明确未执行的排队项暂停后重新核验原账号。历史补发通过现有可追溯后续任务接口续接，保留旧快照与去重占位。不会修改已提交回执，不会恢复原本手动暂停的计划。

## 无扩展运行

2026-10-13用户决定移除日常 Chrome 的 OpenClaw 扩展。社区配置增加 `community_browser_execution: "web"`，并移除本机工作台中继绑定。平台代理能力保留在代码中，实际运行能力由 `publication_platform` 按当前配置派生；网页发布和自动平台可并存，不修改静态注册表。服务层、每日计划与真实适配器分别拦截自动发送；旧账号身份不能让页面误报执行连接可用。

本机现有贴吧/掘金计划与15项确定未开始的历史任务继续暂停。用户可在内容详情把无回执的原任务显式改为网页发布，原正文快照、账号、身份、去重占位不变；结果不明或平台风险不能通过此入口绕过。网页提交后登记链接，只计为用户登记。工作台不需要配对；这不代表仍能无人值守发送。扩展移除通过 Chrome 自身界面完成，其他扩展、OpenClaw 服务和浏览器资料保留。
