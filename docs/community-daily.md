# 贴吧每日帖子与评论

社区发布的五个页签为：帖子、评论、每日计划、账号、平台。贴吧支持文字主题帖与已有主题帖的顶层评论，暂不含楼中楼。分别展示完整正文、目标、原帖上下文、状态及回执链接；平台接收不等于公开可见。

## 使用

每日计划默认北京时间10:00开始，目标每天1篇主题帖、评论5个不同帖子。配置主题素材、指定帖子评论以及可选自动匹配规则；启用固定账号身份、账号版本和代码版本。计划不需要逐条人工审核。普通讨论的自动匹配评论不能带网址或联系方式；指定推广入口可配置带链接的相关介绍。

每天选用未用主题素材；指定评论优先，其次从最多3个已配置贴吧读取最近30天的最多18个候选，核对原帖标题、正文、作者和规则匹配。关键词必须出现在原帖实际内容里，求助规则要求问题表达，排除明显售卖/网盘推广等内容。每条评论素材/规则只使用一次，不通过同义改写制造新内容。素材或相关目标不足时明示缺口，不承诺每天一定找到5条合适内容。

保存不启动；启用按时间安排；“立即安排今天”只创建一次当日任务，发送仍遵守共享间隔。暂停停止后续安排及尚未提交队列；重新启用不自动恢复已暂停任务。服务重启不补往日任务，到下次每日开始时间仍未发送的旧计划任务取消并保留记录；晚间首测可按间隔正常跨午夜完成。准备阶段中断会暂停计划；提交阶段中断使用unknown锁定机制。平台限制/不确定回执同时暂停计划。

贴吧共享30分钟最小间隔、滚动24小时最多6次尝试，并按上海日期限制1篇主题帖+5条评论；其他社区保留原24小时5次。所有同平台账号共享预算。这是本地保护约束，不是平台承诺的安全阈值。相同平台身份对同一主题帖永久不重复评论，规范化相同正文跨目标拒绝；占位/去重持久保存，暂停、失败、换一天或重启不能规避。

## 架构

新增community_claims、community_plans、community_plan_days、community_plan_items；主题/评论继续共用原community_posts/jobs。新账本仅补充旧任务索引，不改原快照/回执。每日任务创建、提交占位和计划归属在同一事务内；日期唯一键、素材唯一键和目标/内容账本分别保护。

- daily.py：选材、上海日期安排和计划状态。
- service.py：持久化队列、身份、去重、共享预算与风险。
- adapters.py：正常页面操作、目标与原文核对、单次请求及明确回执。
- community-daily.js：计划和素材表单；community.js：帖子与评论历史。
- API：POST/PUT /api/community/plans[/id]；POST /api/community/plans/{id}/enable|pause|today。

tests/test_community_daily.py、tests/test_community_replies.py、scripts/verify_community_daily_ui.py和scripts/verify_tieba_replies.py均使用隔离库或网络拦截夹具。真实发送仅在用户明确授权的测试中使用实际账号。
