# 日常 Chrome 社区执行连接

社区浏览器适配器支持显式绑定的 OpenClaw 扩展中继。原来的独立账号浏览器模式仍按旧配置使用；日常 Chrome 不会自动启动独立资料目录。

本机管理员配置（仅写入 var/config.local.json，不提交账号或凭据）：

- `community_relay_accounts`：明确授权绑定的社区账号 ID 列表。
- `community_relay_port`：本机扩展中继端口。
- `community_relay_secret_file`：OpenClaw 本机配对凭据文件路径。内容不放进 URL、API 返回或错误消息。

扩展必须在用户日常 Chrome 完成配对，并将对应平台页面加入 OpenClaw 共享标签组。连接只接受 127.0.0.1 上的指定端口，HTTP 禁用代理及重定向；CDP 端点严格限定同端口 `/cdp`。对应平台共享标签不存在时停止，不读取其他浏览器、不复制 Cookie。

传输可用之后仍由平台适配器核对原账号稳定 ID；账号不符、验证码、未知回执及平台限制沿用原停止机制。`check`、候选读取和发布使用同一个注入连接。掘金身份读取兼容新版头像菜单，不能使用正文作者链接推断当前账号。

本次验证覆盖：模拟传输拒绝非本机端点、凭据不泄露、共享平台校验、不回退到独立 Chrome，以及原账号真实只读核验。连接验证不代表已发帖或评论；结果以每条业务回执为准。
