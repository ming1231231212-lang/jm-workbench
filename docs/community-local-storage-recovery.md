# 本机状态文件访问异常恢复

2026-10-20 知乎在提交前发生 PermissionError。原通用异常分支将其包装为 PreflightStopped，服务把任务标记为失败并暂停整个平台的计划；没有消耗提交占位，但也不会自行恢复。

本机证据是失败时刻遗留的固定 `.tmp` 文件，内容与两秒前保存的状态文件完全一致。原实现每次读取页面后都重写状态，并立即替换目标文件。Windows 文件不允许删除共享时，该替换可以抛出 PermissionError；真实 Windows 文件句柄测试复现了 WinError 5。旧日志没有堆栈，不能据此确定当时哪个进程占用文件，也不能归因为平台风控。

修复包括：

- 内容未改变时不重写文件；真正变更使用本次独有的临时文件，原子替换最多尝试 4 次，只重试文件保存，不重复网页点击。失败保留旧状态，清理仅限本次临时文件。
- 锁、通道初始化及网页准备中的 PermissionError，只在持久提交占位之前转成队列等待，采用既有 5/10/20/30 分钟退避，保留同一内容及账号，不暂停平台计划。人工停止、身份变化和真实平台限制仍优先。
- 提交占位之后发生错误仍进入结果不明保护，绝不自动补发。保留预算校验的原有异常分类，不将共享额度等待误转成永久失败。
- 回执保留安全的错误类别、系统错误码、文件名和代码位置；不记录异常原文、局部变量或正文。成功恢复后仍保留预检历史。

相关验证覆盖真实 Windows 文件占用、无变化不写、有限保存重试、原状态保留、初始化异常、提交前恢复、提交后不重发、服务重启、人工暂停优先、每日 01:00 三平台只发帖子、跨日回执及原稿续接。真实账号结果另存本地 outputs，不提交到版本库。

持续权限故障会保持等待并记录原因，需要修复本机环境；本修复不把等待或模拟测试当成真实发布成功。
