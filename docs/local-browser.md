覆盖：社区账号网站、发帖结果、账号管理、采集原视频、社区原帖、SAU 管理页面、JM 启动脚本。前端将新窗口网页链接（含中键）交给带本机 CSRF 校验的 /api/browser/open。站内路由、下载仍按原流程。

设置新增 browser_open_mode，默认 daily；account 是用户主动选择的旧任务兼容模式。配置缺失时也用 daily。后台连接恢复在 daily 模式下不启动任何独立 Chrome。

## 网页登录和自动任务

日常 Chrome 的网页登录不等于原绑定执行账号已核验。既有执行器仍验证原账号资料目录与平台身份，不能读取一个浏览器的登录却在另一个浏览器自动发布。页面提示改为“打开网站”和“检查执行连接”；账号状态显示“执行账号已核验”。旧任务记录、素材、账号身份及风险状态不迁移、不清除。

本次不实现日常 Chrome 自动控制桥接，不读取或复制 Cookie，不重启用户浏览器。旧执行连接不可用时停止发布并说明原因。SAU 管理页会在日常 Chrome 打开；SAU 内部的扫码登录与自动上传属于它自己的执行器，不代表本次已迁移其登录机制。
