# 日常 Chrome 本机执行组件

2026-10-14。本组件通过 Windows UI Automation 操作日常 Chrome 的任务专用标签，不安装扩展、不连接 CDP、不复制登录资料。

## 当前范围

- `NativeChromeChannel` 绑定已核对的任务标签运行时标识，检查 Chrome 程序、目标 URL、窗口前台和控件遮挡。标签被改用于其他页面时停止，不覆盖其他工作。
- `NativePublisher` 已实现知乎文章评论的单次提交和本人登录视图核验。贴吧、掘金支持原账号本人主页只读检查，自动文章发布及每日调度尚未由本组件接入。
- 注册表、现有自动发布开关和每日计划不因组件存在而改变。网页登记仍显示“已登记 · 待核验”，不能冒充自动平台回执或未登录公开可见性。

## 发送边界

调用方负责固定内容和账号快照，先持久占位，检查原计划暂停、平台风险、每日与滚动额度、发送间隔，再调用执行组件。`before_submit` 在唯一提交动作前再次检查并持久记录尝试。提交动作开始后出现超时或无法核验，只返回 `NativeUnknown`，禁止重发。

发送前检查本人主页所有权、原帖标题与具体正文、当前登录名称和输入框完整正文。原有未发送输入不会被覆盖。提交后要求编辑器清空，完整评论和对应作者主页出现在原帖中。

知乎评论可能使用另一种本人主页地址。别名必须先实际打开，并通过本人编辑资料入口核验；只允许重定向到预先绑定的本人主页。相同昵称不能证明账号相同，不能为了让测试通过而忽略作者链接。

## 代码与测试

- `jm_workbench/community/native.py`：独立发布契约和保守停止语义，不启用调度，不处理凭据。
- `jm_workbench/community/native_channel.py`：受限进程、任务标签绑定、精确的主页别名跳转。
- `scripts/native_chrome.ps1`：有深度、节点数和重复节点保护的 UIA 读取，写入前检查目标和遮挡。
- `tests/test_native_community.py`：正文、原文、身份和重复检查；提交结果不明只尝试一次；提交前暂停；主页别名所有权及精确跳转。

开发时使用独立工作目录，完成测试后再部署。本项目运行服务拒绝向已经变动但尚未重启加载的代码提交写入，不能绕过该保护。停止或重启只针对已核对的 JM 服务进程，保留日常 Chrome 和所有账号登录。
