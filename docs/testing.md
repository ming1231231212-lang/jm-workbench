# JM工作台验收与评测

## 功能与验证映射

| 用户要求 | 实现位置 | 验证 |
|---|---|---|
| JM名称及新界面 | web/static | API标题、8模块、桌面/手机实测 |
| 陪玩与成人尾货 | policies/rules.py、services/engine.py | 正负样本、跨业务模板拒绝、详情变化停发 |
| 平台和账号矩阵 | core/models.py、configuration.py | 7平台注册、不同平台拒绝、资料目录隔离 |
| 一键执行 | configuration.launch、engine | 完整预检、重复点击幂等、固定快照、停止 |
| 爬虫整合 | adapters/crawler*.py | 7平台参数、依赖导入、实际快手只读采集 |
| 发布保护 | guard.py、kuaishou.py | 共享频率、历史去重、占位、未知结果停止 |
| 后续迭代 | docs、测试、分功能提交 | pytest、Node test、CI |

## 必须保持的回归场景

1. 搜索结果混有推荐内容；只读取准确关键词响应。
2. 搜索页面与当前关键词不一致；拒绝归属该关键词。
3. 视频自动跳转到下一条；旧视频详情不能用于发送。
4. 评论权限缺失、布尔值或未知枚举；不默认允许。
5. 本店成人品类库存清货为正例；同行收货、加盟、新闻、消费者、泛话题为负例。
6. 陪玩成年求职为正例；未成年、没有成年证据、其他招聘方、泛游戏为负例。
7. 同视频已有旧记录，或作者/文本近期接触；跳过。
8. 用户停止、身份切换、配置变更、重复启动；不串账号、不重复发布。
9. 发送超时或服务中断；持久化未知结果，不自动重发、不切换同平台账号继续。
10. UI保存按钮通过fetch提交，避免原生页面导航与CDP连接互相等待。
11. 数据包含HTML、脚本或CSV公式；转义显示，导出防公式执行。
12. 同一数据目录启动两个执行器；第二个拒绝启动。

## 执行验证

- 离线：`python -m pytest`及`npm test`。
- 页面：复制数据库到独立验收目录，启动`python -m jm_workbench --port 8777 --home <验收目录> --no-worker`，然后运行`python -m scripts.check_ui <专用Chrome资料目录>`。
- 真实平台：仅进行选定账号身份核验与有限的关键词读取；不使用真实评论作为测试。
- 其他平台：当前检验适配器参数、外部模块可导入；需逐个平台登录后补充实际读取结果，不能据此宣称7个平台均在线实测成功。

所有本机验收JSON、截图和导出样本在outputs下保存，不入Git。
