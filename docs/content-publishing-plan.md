- SAU Web API 实际路由仅 4 类：小红书(1)、视频号(2)、抖音(3)、快手(4)。其余 CLI 平台不冒充已接入。
- 复用 SAU 本机服务，账号与登录态保留 SAU 管理；JM 只保存账号引用和任务快照，不在浏览器返回 Cookie 路径或内容。
- 发布服务本机连接、逐视频逐账号执行；UI 200 不等于视频可见。SAU 的通用“已提交”回执单独记为 submitted，不能冒充已发布核验。
- 排队任务持久化；发送前占位；中断/超时/未知结果禁止自动重发；复用平台风险锁和本机浏览器互斥。
- 定时由 JM 持久队列按本机时间执行，不依赖 SAU 小红书存在缺陷的原生定时参数。
- 保留已有评论、爬虫、分类数据、账号矩阵和守护功能，升级须处理版本校验与历史队列。
- 自动化测试使用模拟 SAU，不真实上传/发布用户内容。不提供零风险或全平台实际发布已验证的保证。
