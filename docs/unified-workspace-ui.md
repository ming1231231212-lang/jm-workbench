## 本轮修复

1. 快速切换模块时，迟到请求不能覆盖当前页面。
2. 弹窗提交失败的具体原因在弹窗内可见，保留填写内容。

4. 密度在全部模块一致，继承已有社区偏好；手机导航关闭后不可被键盘误选。
