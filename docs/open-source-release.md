# 公开开源发行

JM 自有代码使用根目录 MIT 许可证。允许使用、修改和再分发，包括商业使用，但必须保留许可证和版权声明。第三方组件分别适用自己的授权，见 `packaging/THIRD_PARTY_NOTICES.md`。

v1.1.1 是首个包含 JM MIT 许可证的公开发行包。在 v1.1.0 已验证的业务代码基础上更新版本和交付文档，补齐发行包中的 JM 许可、图标来源通知；业务配置和发送规则未变化。

## 发布过程

1. 审计将公开的分支、标签历史、发行附件和构建产物；排除真实账号、密钥、数据库和业务记录。
2. 将源码提交、推送，创建与源码版本一致的标签和草稿 Release。
3. 手动触发 Windows portable package 工作流，ref 使用该标签，release_tag 填写相同标签。
4. 工作流运行 Python / JavaScript 回归、Windows 构建和实际 EXE 验收，再验证全部包文件的 SHA256、ZIP CRC，并上传草稿附件。
5. 检查 CI、包清单、测试报告和 GitHub 资产 digest；发布后使用未携带凭据的请求核验源码及 Windows ZIP 可下载。

仅构建与验收通过后上传到草稿，不自动发布草稿或改变仓库可见性。Windows 10/11 x64 为目标系统；本地已有 Windows 11 验收，独立 CI 为 Windows Server 2025，Windows 10 未进行真机测试。

## 用户数据

首次启动为空工作台。接收者自己添加账号、登录和配置内容。源代码与发行包不附带维护者的账号、浏览器会话、业务数据或平台授权。未知回执、手动暂停和平台限制继续沿用原有保护规则。
