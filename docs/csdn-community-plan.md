# CSDN 社区接入与第三站测试

用户授权继续测试第三个社区，已完成账号专用 Chrome 手机号登录。沿用每日1篇技术文章、5条不同目标评论、原文核验、同平台共享预算及未知回执不重发。

## 实施

1. 原生页面和请求结构检查：完成。Markdown编辑器直接fill丢换行，采用原生文件导入并逐字回读；原生发布设置选择已存在标签、AI辅助创作声明，关闭GitCode备份和多平台同步。评论读取原文与作者后通过正常编辑器提交。
2. 适配器、账号同步、每日计划与界面：完成。CSDN独立模块，不把文章作者误当当前登录用户；身份来自本人工具栏主页链接。文章与评论请求均单次拦截校验后放行，结果码及内容编号必须明确。
3. 模拟测试、浏览器请求契约与界面检查：完成。平台拒绝、未知回执、重复目标、跨账号预算、草稿保留及额外同步禁止分别验证。
4. 备份后部署、正式测试与GitHub CI：待完成。

## 当前能力边界

- 发文为个人博客，标签按每篇内容配置，不创建专栏、不备份到第三方、不参与活动。
- 评论当前使用已核对原文的指定帖子素材。原生搜索尚未验收，保存含CSDN自动搜索来源/规则的计划会明确拒绝，不伪装为可以自动发现目标。
- 每日与24小时额度、30分钟间隔属于本地保护设置，不是平台保证的安全额度。
- 回执表示平台接收，公开可见另行核验；任何拒绝或未知结果均停止，不更换账号或IP。
- 真实账号、正文、数据库、浏览器资料与平台证据保存在忽略目录，不提交Git。
