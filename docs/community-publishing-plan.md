# 社区发布接入计划（2026-10-03）

## 目标与范围
将研究清单中的国内10个、国外10个平台纳入JM工作台社区发布模块。统一草稿、平台/账号、目标板块、立即/定时执行、暂停/取消、逐目标回执。保留原评论、采集、SAU视频发布及数据。

平台能力分级而非统一假装可自动发帖：百度贴吧实现账号浏览器适配（需登录与身份核验）；DEV、X、Reddit、Hugging Face Hub使用已核验文档的API；其余平台提供真实的网页发布交接、正文复制与链接归档，明确尚无自动提交适配器。Hacker News仅允许本人网页操作，不自动填充/提交。自动发布必须先配置凭据并只读核验身份；没有账号时交付为待配置，不能宣称真实平台发布测试通过。

## 设计规范
用途：在一个工作台管理各社区的帖子及发送状态。风格：克制的工具界面（Industrial/utilitarian）。沿用已部署品牌与组件：背景#f7f8f6、侧栏#fcfdfb、主色#24745b、正文#252b29、边框#e6ebe4；字体Microsoft YaHei UI / Microsoft YaHei / Segoe UI。左侧全局导航、右侧宽内容区；模块三个页签，编辑对话框采用正文宽列与目标设置窄列。沿用现有CSS与原生JS模块，不引入CloudBase或新前端框架；用户简洁要求及已有设计系统优先。

## 分层与保护
community/registry.py声明20个平台能力；models.py输入校验；adapters.py官方API与浏览器协议；service.py持久化及队列；api.py路由；community.js/CSS为UI。凭据保存在被Git忽略的运行目录，Windows DPAPI加密；API不回显。账号身份固定；修改凭据或账号使旧核验失效。发送前事务占位；重复点击幂等；不确定回执暂停该平台，绝不自动重发；验证码/权限/限流暂停；不切账号或IP。跨账号采用平台预算。手工交接不标为已发布，用户登记链接也标明“用户登记，未核验”。
