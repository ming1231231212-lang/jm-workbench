JM工作台

Windows 10 / 11 · 64 位 · 免安装版

第一次使用，做这三步

  1. 完整解压 ZIP。放在普通本地文件夹，例如“文档\JM工作台”。不要直接在压缩包内打开，不要单独移动 EXE。
  2. 双击「JM工作台.exe」。等待工作台页面自动打开。无需安装 Python、Node、FFmpeg；没有 Chrome 时使用随包浏览器。
  3. 添加你自己的账号，保存内容和任务配置。社区发布选择平台 → 添加账号 → 登录 / 检查连接 → 创建帖子或计划；视频发布到“账号”页登录发布账号，再上传素材。

首次启动没有预置账号、历史记录或自动发布计划。保存配置后，请检查具体账号、目标和文案，再开始任务。

功能怎么用

模块使用条件
社区发布帖子、评论、账号、计划、回执集中管理。百度贴吧、掘金等入口按各平台实际能力开放；掘金的自动评论保持关闭。列表中的平台不代表都支持自动发布。
视频发布内置本地 SAU 接入组件。支持配置快手、抖音、小红书、视频号账号；需本人登录，并具备平台发布权限。先上传视频，再配置发布内容。
快手采集 / 评论基础关键词采集与评论使用内置组件；需登录、匹配任务和账号。每条通过筛选的视频最多一条评论，同时受平台共享频次和去重规则限制。
其他平台采集需要用户另行配置有合法使用权限的爬虫环境。MediaCrawler 未随包提供，其许可证限制非商业学习用途。
数据中心 / 运行记录查看采集分类、任务进度、提交内容和平台回执。“已提交”与“已公开可见”是不同状态。

关闭、故障和每天执行

  • 关闭网页后，工作台仍在后台运行；双击「退出工作台.exe」才会停止本发行包的后台服务。
  • 后台监护会在服务进程异常退出时尝试恢复；手动退出、任务暂停、平台限制和不确定回执都不会被自动取消。
  • 电脑必须开机、联网且处于唤醒状态，任务才能按时执行。此版本不会擅自修改电脑的睡眠或开机启动设置。
  • 打不开时先运行「环境检查.exe」。诊断页会显示运行环境和日志位置。首次打开未签名程序时，Windows 可能显示来源提示；请核对 GitHub 发布页的文件校验值和来源。

你的数据在哪里

账号、任务、浏览器登录、素材和日志保存到当前 Windows 用户的 %LOCALAPPDATA%\JMWorkbench。程序目录可以换位置；升级时先退出旧版，再解压新版并打开，新版会继续读取同一数据目录。

备份前退出工作台，再复制上述整个数据目录。登录密钥采用当前 Windows 用户绑定的保护方式，迁移到另一台电脑或另一位 Windows 用户时需重新登录。不要把这个数据目录随程序转发给别人。
